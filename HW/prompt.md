# 近世代数作业修复与批改

## 任务目标

对 `hwxx.tex` 中的作业题 (problem) 与解答 (solution) 进行 LaTeX 格式修复与数学错误订正。

## 具体要求

- **格式修复**：将 `hwxx.tex` 中 problem 和 solution 的文字修复为正确的 LaTeX 代码（无需指出 LaTeX 语法错误）。
- **数学订正**：订正 solution 中的所有数学错误（指出所有数学错误）。
- **忠于原意**：除非数学过程有误或为了必要的严谨性，否则禁止修改原先证明思路或者添加多余的说明文字。
- **语言风格**：保持证明的简洁，不需要过多说明文字，保持原有语言风格。不要使用“这意味着”、“注意到”、“显然”、“知”、“进一步”、“可知”及“故”等书面化、陈述性的虚词，转而使用更自然、直接的口语化或客观陈述语言（如“即”、“由于”、“得到”、“所以”、“因此”，“但是”等）进行逻辑衔接。
- **排版规范**：确保渲染出的文字的格式美观整洁，有清晰的缩进和换行。
